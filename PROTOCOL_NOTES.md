# Протоколы и проверка

## Основание реализации

- ACC поставляется с Broadcasting SDK:
  `SteamApps/common/Assetto Corsa Competizione/sdk/broadcasting/Sources`.
- Публичное описание/структуры Broadcasting v4:
  https://github.com/prule/acc-messages/tree/main/ksy
  (Kunos SDK field layout, использовано как описание формата, не runtime dependency).
- Документация Kunos shared memory:
  https://www.assettocorsa.net/forum/index.php?threads/acc-shared-memory-documentation.59965/
- Публичный пример Windows-структур:
  https://github.com/IkoRein/ACC_ShmemUDP_Relay/blob/master/ConsoleApplication1/SharedFileOut.h
- Известная неоднозначность ветра в ACC:
  https://www.assettocorsa.net/forum/index.php?threads/acc-shared-memory-documentation.59965/page-10

Реализация парсера написана на стандартной библиотеке Python. Форматы little-endian;
строки UDP имеют uint16-длину в байтах UTF-8; shared memory использует
UTF-16LE, int32/float32 и упаковку 4 байта. Python `wchar_t` намеренно не применяется:
на Linux его размер отличается от Windows.

Регистрация: outbound 1/version 4, display name, connection password, интервал
100 мс, пустой command password. При успехе — запросы entry list (10) и track data
(11). На завершении — unregister (9). UDP-сокет подключается к порту ACC с
**эфемерного локального порта**, а не захватывает порт игры. Автоповтор регистрации
при отсутствии входящих данных — каждые 5 секунд, таймаут чтения — 0.5 секунды.

Все машинные ID хранятся в словаре; ID не является индексом позиции/порядком списка.
Фокус камеры отдельно от playerCarID. После смены индекса сессии история гонки
сбрасывается. Парсер сначала проверяет полный пакет и конечность float, затем
изменяет модель под lock. UI получает независимый snapshot.

## Ручная приёмка на Windows с ACC

Эти пункты **не считаются пройденными** синтетическими тестами:

- [ ] Запустить `python -m acc_telemetry --demo`: позиции, таблица, PSI/core, карта.
- [ ] Правильно настроить broadcasting.json, загрузить живую сессию.
- [ ] Получить одновременно `UDP ON` и `MEMORY ON`.
- [ ] Сравнить скорость, RPM, R/N/1–6, топливо (л), давления (psi) и температуры
  с HUD/данными игры; проверить порядок FL/FR/RL/RR.
- [ ] Проверить соответствие playerCarID игроку и названий моделей соперникам.
- [ ] Переключить фокус камеры: собственная физика не должна стать физикой соперника.
- [ ] Сравнить позиции при обгонах; убедиться, что оценочные интервалы помечены `≈`.
- [ ] Проверить карту с реальным контуром в правильных мировых координатах.
- [ ] Перезапустить сессию, сменить трассу, проверить очистку истории/следа.
- [ ] Закрыть/перезапустить игру: исчезновение устаревших показаний и восстановление.
- [ ] Неверный пароль: видимая ошибка регистрации, без вывода пароля.
- [ ] Проверить демо → live → reconnect несколько раз, без дублирования потоков.
- [ ] Проверить удалённый UDP с другого ПК: нет ложных локальных шин/топлива.
- [ ] Собрать exe на Windows, запустить демо и live из exe без установленного Python.

Готовые реальные карты всех трасс, калиброванное направление ветра и настоящие
3D-модели автомобилей в эту реализацию не входят; README перечисляет это явно.
