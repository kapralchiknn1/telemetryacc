# Контуры трасс

`demo.json` — **вымышленная демонстрационная трасса**, не Monza/Spa и не карта ACC.
Для реальной трассы добавьте файл `<имя_из_ACC_в_нижнем_регистре>.json`, заменив
пробелы/дефисы на `_`, либо передайте `--track-map путь/к/файлу.json`.

Формат: `{"points": [[x, y], [x, y], ...]}`. Используйте мировые метры:
`x/z` из shared memory или `WorldPosX/WorldPosY` Broadcasting SDK. Минимум три
различимые точки. Контур замыкается при отображении. Схематичные картинки и
нормализованные координаты 0..1 не совпадут с машинами без преобразования.

Без файла приложение честно рисует записанный след выбранной машины, а не
соединяет позиции соперников в выдуманную «трассу». След хранится только в памяти.
