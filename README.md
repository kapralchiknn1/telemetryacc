# ACC Telemetry Dashboard

Настольная панель для **Assetto Corsa Competizione** на Python 3.10+ / Tkinter.
Поддерживает настоящий **ACC Broadcasting SDK v4** и локальную **Windows shared
memory**. Демо работает без игры и без сетевых подключений.

> Старая реализация «local telemetry / magic 0x4571234F» и настройка через
> Content Manager не относятся к поддерживаемому здесь протоколу ACC и удалены.

## Что показывает

- Позиции пилотов из игры, имена, номера, класс, модель машины и пит-статус.
- Отставание от лидера и интервал: в гонке — **оценка `≈` по времени прохождения
  одинаковых точек трассы**, а не выдуманные секунды из расстояния по прямой.
  После подключения нужно дождаться, пока машины пройдут общие точки.
  В тренировке/квалификации показывается разница лучших кругов.
- Карту с позициями всех доступных машин. При наличии подходящего JSON — контур
  трассы; иначе постепенно накапливаемый **след** выбранной/своей машины.
- Скорость своей машины, RPM, передачу (включая R/N), топливо в **литрах**,
  газ/тормоз, номер круга, текущее и лучшее время.
- Температуру ядра каждой шины в °C и давление в **psi**.
- Температуру воздуха и асфальта, влажность из Broadcasting API, скорость ветра.
- Стилизованную **2D-схему** соперника и его настоящее название модели.
  Это не 3D-модель конкретного автомобиля. Выбор соперника — кликом по таблице.

Отсутствующие или устаревшие данные отображаются как `--`, не как нулевые показания.
`DEMO` явно отмечен и никогда не подменяет данные живой сессии автоматически.

## Быстрый запуск без игры

Установите Python 3.10 или новее. В установщике Windows оставьте компонент
**Tcl/Tk and IDLE**. Откройте терминал в папке репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m acc_telemetry --demo
```

Демо генерирует тестовые машины и телеметрию внутри процесса, без UDP, случайных
портов и ограничений бинарных полей. Работает на Windows, Linux и macOS с Tk.
В Linux может потребоваться системный пакет `python3-tk`/`python3-tkinter`.

Также сохранён запуск:

```powershell
python acc_telemetry/app.py --demo
```

## Подключение к ACC на Windows

Для **полной телеметрии** запускайте панель на том же Windows-ПК, что и ACC.

1. Закройте ACC.
2. Откройте файл:
   `%USERPROFILE%\Documents\Assetto Corsa Competizione\Config\broadcasting.json`.
   Если документы находятся в OneDrive/другой папке, используйте реальный путь.
3. Укажите настройки Broadcasting API, например:

   ```json
   {
     "updListenerPort": 9000,
     "connectionPassword": "replace-with-your-own-local-password",
     "commandPassword": ""
   }
   ```

   Имя `updListenerPort` с таким написанием используется самим ACC.
   **Выберите свой локальный пароль**, не публикуйте файл в репозитории.
   Если файл уже содержит другие поля, сохраните их.
4. Запустите ACC и загрузите сессию/выйдите на трассу.
5. Запустите панель:

   ```powershell
   python -m acc_telemetry
   ```

Приложение автоматически читает порт и пароль из стандартного пути выше.
Если путь другой:

```powershell
python -m acc_telemetry --config "C:\путь\к\broadcasting.json"
```

Порт можно переопределить через `--port 9000`. Пароль также можно передать через
переменную окружения `ACC_CONNECTION_PASSWORD`: она имеет приоритет над файлом.
Аргумента командной строки для пароля нет, чтобы не оставлять его в истории.
Пароль используется только для регистрации в ACC, не записывается в файлы/логи.

**Shared memory** (`Local\acpmf_physics`, `Local\acpmf_graphics`, `Local\acpmf_static`)
читается только на Windows, только на чтение. Приложение не создаёт пустые
mapping-объекты вместо отсутствующей игры. Дополнительный плагин ACC не требуется.

## Другой компьютер / только Broadcasting API

```powershell
python -m acc_telemetry --host 192.168.1.10 --port 9000 --config "C:\local\broadcasting.json"
```

На ПК с игрой разрешите UDP-порт ACC в брандмауэре **для доверенной локальной
сети**. Не открывайте его в Интернет. Пароль Broadcasting API передаётся протоколом
без шифрования. Приложение регистрируется без command password и не отправляет
команды управления камерой или игрой.

При удалённом `--host` shared memory намеренно отключена: нельзя смешивать чужую
сессию UDP с данными локальной игры. Доступны позиции, пилоты, модели, карта и
данные сессии; RPM, шины, топливо, педали и ветер недоступны. При отсутствии
shared memory жёлтая машина на карте — **фокус Broadcasting API**, не обязательно
игрок. Панель собственной физической телеметрии остаётся пустой.

## Управление

- **Демо без игры / Выйти из демо** — останавливает и дожидается завершения прежних
  источников, сбрасывает данные и запускает выбранный режим.
- **Переподключить** — перезапускает текущий режим без дублирования приёмников.
- **Полный экран**, `Esc` — включить / выйти из полноэкранного режима.
- Колесо мыши на карте — масштаб; двойной клик — сброс.
- Клик по пилоту в таблице — выбрать соперника в панели 2D-схемы.
- `UDP ON/OFF` и `MEMORY ON/OFF` показывают источники отдельно.

## Контуры трасс

Реальных готовых контуров всех трасс в этом репозитории **нет**. `tracks/demo.json`
— вымышленный контур только для демо. Живая карта без контура всё равно показывает
машины в мировой системе координат и накопленный след, без ложной «трассы» из
линии между соперниками.

Можно добавить контур самостоятельно:

```json
{"points": [[0, 0], [100, 0], [80, 100], [0, 80]]}
```

Это пример формата, **не реальная трасса**. Нужны мировые координаты именно вашей
трассы: `WorldPosX/WorldPosY` Broadcasting SDK или `x/z` shared memory, **в метрах**.
Загрузите файл:

```powershell
python -m acc_telemetry --track-map "C:\maps\spa.json"
```

Или положите JSON в `tracks/<имя_трассы>.json`: нижний регистр, пробелы/дефисы
заменены на `_`. Пример: `spa.json` для имени `spa` из ACC. Подробности в
[tracks/README.md](tracks/README.md). Пользовательский контур применяется в живом
режиме, в демо всегда используется демонстрационный. Для другой трассы перезапустите
панель с соответствующим `--track-map`.

## Важные ограничения

- Интервалы в гонке оцениваются из наблюдаемых пересечений 200 точек сплайна;
  это не официальный timing feed. `--` означает, что общей истории недостаточно
  либо машины остановились/переместились. После смены сессии история сбрасывается.
- Модели автомобилей определяются по ID SDK. Новая неизвестная модель показывается
  как `Модель ID N`, а не угадывается. Схема машины условная.
- Шинные значения — **core temperature** и давление, не износ и не температура
  всех слоёв. Цвет температуры — иллюстрация, не рекомендация по настройке шин.
- Скорость ветра переводится из фактических km/h ACC в m/s. **Направление пока
  отображается как `Курс ACC (raw)` без градусов/сторон света**: документация SDK
  и наблюдаемые значения расходятся. Калиброванная роза ветров ещё не реализована.
- На паузе/после закрытия ACC остановившийся поток памяти становится устаревшим;
  физические показания скрываются примерно через 3 секунды. Позиции исчезают
  примерно через 5 секунд без обновлений. Статус UDP не означает наличие физики.
- Поддерживается формат SDK v4 и стабильные префиксы Windows shared memory.
  Проверка на реальной установленной ACC обязательна; мок-сервер и фикстуры не
  заменяют эту проверку.

## Тесты

```powershell
python -m unittest discover -s tests -v
python -m compileall -q acc_telemetry tests
```

Покрыты бинарные пакеты v4, Unicode, R/N/передачи, неизвестные модели, усечённые
пакеты/NaN, shared-memory offsets и единицы, интервалы, потокобезопасные снимки,
устаревание, переключения демо и UDP-мок регистрации/отключения. Tk smoke-test
проверяет настоящее окно, если доступны Tk и дисплей; иначе явно пропускается.
В Linux его можно запускать через `xvfb-run`.

Шаблоны GitHub Actions находятся в `docs/workflow-examples/`: тесты на
Windows/Linux и Python 3.10/3.13, а также ручная Windows-сборка exe с artifact.
**Автоматизация пока не включена**: текущее подключение GitHub отклонило запись
файлов в `.github/workflows/`. Владелец репозитория может вручную скопировать
шаблоны в `.github/workflows/` и закоммитить их с нужными разрешениями.
После этого workflow **Build Windows executable** запускается вручную.
Наличие шаблонов само по себе не означает, что Windows-сборка уже проверена.

## Сборка .exe — только на Windows

```powershell
python -m pip install "pyinstaller>=6.11,<7"
pyinstaller --clean --noconfirm acc_telemetry.spec
```

Результат: `dist/acc_telemetry.exe`. Каталог `tracks` включается в сборку.
PyInstaller не является зависимостью для запуска исходников. Чтобы менять карты
без пересборки, используйте внешний JSON с `--track-map`.

## Структура

```text
acc_telemetry/
  app.py              # Tkinter, единый снимок данных на кадр
  config.py           # CLI и безопасное чтение broadcasting.json
  model.py            # модели, lock/snapshot, оценка timing-интервалов
  acc_udp.py          # ACC Broadcasting v4: регистрация, запросы, парсинг
  shared_memory.py    # локальная физика и данные игрока, только чтение
  feeds.py            # жизненный цикл потоков и переключение источников
  demo_feed.py        # автономная симуляция без сокетов
  track_map.py        # демонстрационный контур и валидация JSON
  widgets/            # карта, таблица, приборы и 2D-схема
tracks/               # пользовательские контуры + demo.json
tests/               # unit, integration и Tk smoke-test
docs/workflow-examples/ # шаблоны CI/сборки (не активированы)
acc_telemetry.spec    # рецепт Windows exe
```

Спецификации и список ручной проверки: [PROTOCOL_NOTES.md](PROTOCOL_NOTES.md).
